## Description:

Converts a user-selected Markdown file or folder of recent notes into mobile-friendly local HTML pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bonniegeng-max](https://clawhub.ai/user/bonniegeng-max)

### License/Terms of Use:

MIT

## Use Case:

People and developers who receive Markdown notes, reports, or chat exports use this skill to create phone-readable HTML pages locally, including one-level batch exports of a named folder.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Publishing a generated page can disclose content from the selected Markdown file.

Mitigation: Review the HTML before sharing and use a trusted deploy tool only after a separate, explicit confirmation.
